## 左侧导航

顺序固定：

1. **首页 · 新对话**（House 图标）：欢迎语（打字机动画）、Composer、专家选择、分类推荐指令、人资窗口期轮播、基础待办摘要。
2. **服务大厅**
3. **我的成长**
4. **团队洞察**
5. **HR数据运营**

其后是已置顶对话、历史对话列表。导航底部左侧是外观菜单（主题 + 浅色 / 深色），右侧是**待办** Bell 图标：有待办时显示红点，不显示数字。

- 首页与新对话是同一个入口，不再拆开。
- 首页「绩效发展」推荐包含「新员工成长计划」：点击预填「帮我制定新员工成长计划」并选中人才发展专家，发送后进入成长计划场景。
- 角色（员工 / 管理者 / HR）只在服务大厅内组织服务入口，不作为整个应用的顶层视图。
- 当前用户姓名「张益达」，头像简称「达」；申请人、操作人等文案与之一致。

## 页面与 Tab

展示名与内部 route 标识不一致，是有意保留的：改展示文案不需要批量改路由。

| 展示名 | 内部 route | 顶部 Tabs |
| --- | --- | --- |
| 我的成长 | `employee` | 个人信息、新员工专区、我的假勤、我的收入、我的绩效、我的发展 |
| 团队洞察 | `team` | 人才招聘、人才盘点、团队发展、团队出勤、团队状态、团队结构 |
| HR数据运营 | `organization` | 招聘、薪酬、共享运营、干部、人才发展、绩效、股权HRBP、HRD |
| 服务大厅 | `hall` | 员工自助、管理者自助、HR自助 |
| 待办事项 | `tasks` | 待处理、已完成 |

- 顶部 Tabs 放在页面 header 中，统一使用 `HeaderTabs`（宽度不足时折叠进 Tabs 内部的「…」菜单）。
- HR数据运营中「薪酬」位于「招聘」之后；原「运营（含人事）」已改名「共享运营」。
- 团队洞察 / HR数据运营的页面数据在 `features/hr/panorama-data.json`，每个 Tab 都有「值得关注」卡片（蓝绿渐变）、核心指标、看板面板，并可带数据快照召唤 Copilot。
- 人才盘点使用人才九宫格：成员带示意照片（本地头像，不代表真实员工），可查看盘点信息并预填成长建议。

## 服务大厅

- 角色：员工自助、管理者自助、HR自助。header 右侧是搜索与「常用服务」切换。
- 员工分类：全部、人事服务、薪酬福利、学习发展、绩效与改进。
- 管理者不显示单独的「团队管理」分组标题。
- HR 一级分类：全部、薪酬管理、招聘管理、人事服务、人才管理；后两项暂不可点。薪酬管理下的八类业务用**右侧定位锚点**浏览，不做顶部第二排分类筛选。
- 服务卡片描述单行，不显示「进入服务」底部文字按钮。
- 支持 Agent 的入口右上角显示小尺寸 Agent badge；悬停时替换为深灰「召唤」按钮。收藏入口不放在这个位置。
- 当前支持 Agent 的员工入口：调档函、在职证明、收入证明、员工补卡、休假申请。HR 自助的「组织薪酬洞察」是首个专家分析入口。
- 未接通的普通服务可以保持无跳转。

## 三类对话入口

| 入口 | 形态 | 导航 |
| --- | --- | --- |
| 主应用 Agent | 首页发送或打开历史对话，进入完整对话工作区；产物在右侧面板 | 显示 AskHR 左导航 |
| 业务页面 Copilot | 页面 AI 按钮或右下角浮动入口打开右侧面板；支持侧栏、浮窗、进入完整对话 | 保留当前页面 |
| 薪酬智参对话 | 子应用内发起，复用同一套对话组件 | 不显示左导航，顶部首页按钮返回子应用首页 |

Copilot 进入完整对话时：空对话进入首页（带入草稿、专家、上下文），已有对话进入对应完整会话。

## 薪酬智参子应用

- 产品上独立，工程上复用 AskHR：没有第二套构建、依赖或服务。
- 入口：服务大厅 → HR自助 → 薪酬管理 → 组织薪酬洞察。
  - 卡片主体：在浏览器**新页签**打开子应用首页。
  - Agent「召唤」：进入**主应用**首页，并选中薪酬专家。
- 子应用首页不显示 AskHR 左导航，也没有单独的顶部标题栏。
- 两条路径复用同一个薪酬诊断流程：子应用输入「分析显示事业部」，主应用输入「查询显示事业部薪酬情况」。通过项目的 `source` 区分导航显示，不复制业务过程。

## 访问地址

开发服务默认 `http://127.0.0.1:5174/`（`npm run dev -- --host 127.0.0.1 --port 5174`，端口被占用时以终端输出为准）。

| 地址 | 用途 |
| --- | --- |
| `/` | AskHR 首页 |
| `/?appearance=classic`、`/?appearance=glass` | 指定主题（URL 参数优先于记忆的偏好） |
| `/#/compensation` | 薪酬智参首页（静态托管优先用 hash 地址） |

主要业务页面使用内部状态切换，没有独立 URL；自动化测试通过点击左侧导航进入。
