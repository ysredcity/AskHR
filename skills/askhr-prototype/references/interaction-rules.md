## 业务页面触发 AI

- 页面按钮触发 AI：打开右侧 Copilot，预填提示词、专家、技能、来源和数据快照，**等用户发送后才执行**。不跳到首页，不立即执行。
- 按钮图标统一用 lucide `Sparkles`，文案按场景简短命名（如「招聘分析」「分析建议」「档案咨询」）。右下角通用浮动入口同样用 `Sparkles`。
- 业务页上的 AI 主按钮用深灰底白字：`bg-foreground text-background hover:bg-foreground/85`；次级动作用 `outline`。不要换成品牌青绿 `primary`。
- 写法：页面调用 `useHR()` 的 `composeBusiness(intent)`（团队洞察、HR数据运营、九宫格成员）或 `composeEmployee(prompt, skill)`（我的成长）。`BusinessIntent` 的字段为 `prompt`、`skill`、`expert`、`source`、`snapshot`。
  - `snapshot` 是 Markdown 文本，会作为「文件库」上下文的可预览文件带入。团队 / 组织页面用 `panoramaSnapshot(...)` 生成。
  - 用户发送后，`createPanoramaScene` 会按快照中的「关注事项」「建议行动」小节生成回复和一个 Markdown 产物。要沿用这条链路，新快照也应包含这两个 `## ` 小节。

## 专家与上下文

- 专家：假勤专家、薪酬专家、人才发展专家、人才流动专家、人力管理专家（定义在 `features/hr/data.ts`）。
- 专家属于智能体一侧，不出现在用户消息里。
- 专家、技能、来源、数据快照走**同一套上下文机制**：在 Composer 内以内联标签呈现，与用户手动添加的上下文一致。不在输入框上方另做一排标签。
- 我的成长各 Tab 有默认专家映射（`employeeExperts`）：个人信息、新员工专区→人力管理专家；我的假勤→假勤专家；我的收入→薪酬专家；我的绩效、我的发展→人才发展专家。

## Copilot 面板

- 三种形态：侧栏（默认，宽 400px）、浮窗（右下角，400×最高 600px）、进入完整对话。切换入口在面板 header 的模式菜单里。
- 窄于 740px 时 Copilot 全屏覆盖。
- 面板 header：标题、新对话、历史对话、模式切换、关闭。历史对话在面板内切换显示，选中后进入完整对话。
- 对话与产物组件和主应用共用；Copilot 中打开的产物以全屏覆盖层显示。
- 空状态文案：有带入上下文时提示「已带入页面上下文…」，否则提示可以结合页面内容提问。

## 首页与 Composer

- 选择普通专家后隐藏首页推荐分类。服务大厅「召唤」进入首页时，可以通过专门的分类状态展示对应推荐：这是明确的场景例外。
- 推荐分类展开时向下延伸，不推动上方元素。
- 人资窗口期轮播三个场景：PBC 填写、任职资格认证、职称申请。保留左右翻页、右下角紧凑圆点、过渡动画和稳定高度。

## 一次回复的结构

- 同一次智能体回复内部不插入中间操作栏；操作栏在回复末尾。
- 推荐追问放在回复操作栏**下方**。
- 执行过程中，L2 下的 L3 用整合成句子的说明；产生答案后执行过程自动折叠。
- 澄清表单提交后转为只读，多步表单用分页器回看各步字段；**不**额外生成一条重复的「已确认分析条件」用户消息。

## 产物

- 是否自动打开由场景决定，必须在场景说明里写明。现有规则：中间分析产物自动打开，最终报告（如 COE 工作底稿、COE 一页摘要）不自动打开。
- 产物面板内容里的对话框挂载在面板内（`DialogContent container={usePanelPortal()}`），遮罩只覆盖面板，不盖住整个应用。
- HTML 产物预览使用浏览器式工具栏：刷新、地址栏、在新窗口打开。
- 中间步骤的产物不提供下载；最终报告提供「导出」菜单（PDF / Word），**只做展示，不执行真实导出**。
- 报告中已接入的文本区域（结论、根因分析、建议等）悬停显示「引用」「编辑」：引用加入 Composer，编辑后可保存或取消。实现见 `features/compensation/report-notes.ts`。
- 报告里的多个分析 Tab 只有首个生效时，其余可以保持不切换内容，不要补假数据。

## 布局与面板行为

具体数值以 `components/agent-layout/workspace-layout.ts` 为准。

| 条件 | 行为 |
| --- | --- |
| 无产物面板，宽度 ≥ 660px | 左导航可停靠 |
| 有产物面板，宽度 ≥ 980px | 左导航可停靠 |
| Copilot 侧栏打开，宽度 ≥ 1280px | 左导航可停靠；不足时自动收起 |
| 有产物面板，宽度 < 740px | 产物强制全屏 |
| 产物分栏 | 对话区 `clamp(420px, 50%, 800px)`，产物面板最小 320px，可拖动调宽 |

- 1280px 是 Copilot 专用断点，不要与产物面板的 980px 混用。
- 左导航收起后用抽屉打开，抽屉**非模态**，不加遮罩、不阻断后方内容。
- 产物面板拖动已处理指针捕获、释放 / 取消 / 失焦清理，拖动期间 iframe 不吃事件；改动拖动逻辑时保留这些处理。
