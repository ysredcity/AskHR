# 三分区响应式实现

依据：用户提供的《Agent 三分区布局响应式方案》。

## 布局规则

| 宽度 | 无产物 | 打开产物 |
| --- | --- | --- |
| ≥980px | 导航按用户意图停靠 240px；主区填满 | 导航可停靠；对话 clamp(420px, 50%, 800px)；产物吸收余量且不低于 320px |
| 740–979px | 导航仍可停靠 | 导航改为覆盖抽屉 320px；对话与产物并排 |
| 660–739px | 导航仍可停靠 | 导航改为抽屉；产物强制全屏 |
| ≤659px | 导航采用覆盖抽屉；主区取消桌面最小宽度 | 产物强制全屏 |

- 抽屉遮罩覆盖工作区，不再将工作区向右推移。
- 页面均使用同一个“展开导航”入口，根据空间决定恢复停靠或打开抽屉。
- 产物主动全屏时，对话恢复整宽并保留在覆盖层后，不继续保持半宽分栏。
- 导航展开意图、产物主动全屏意图独立保存，窗口缩放只派生布局，不改写意图。
- 业务 GUI 页面不将暂时保留的对话产物计入分栏布局。
- 拖拽宽度限制为 320 至 shellWidth − dockedSidebarWidth − 420；窗口缩小时也受 CSS max-width 约束。
- 全屏产物和导航抽屉打开时，底层工作区不可交互；导航抽屉支持 Escape 和遮罩关闭。
