# HiHR · AI 人资工作台

基于已确认的 V0.2 需求与 Pangea 沉浸式模板制作的桌面端交互原型。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1
```

## 检查与构建

```sh
npm run gate
npm run check:tokens
```

## 可体验的功能

- 首页新对话、示例问题、历史搜索、重命名、置顶、归档。
- 员工自助六个 Tab：个人信息、新员工、假勤、收入、绩效、发展。
- 政策咨询、可打开的引用文档、执行过程与多 Tab 产物面板。
- 年假申请：日期/事由/交接人编辑、校验、确认、提交与撤回；对话与 GUI 同步。
- 岗位筛选、详情、匹配分析、简历文件名选择、确认投递与投递记录。
- 服务大厅四组角色 Tab、分类检索、常用服务。
- 待办确认、请假审批与补充材料的本地演示；团队出勤明细与分析。

## 原型边界

纯前端、示例数据、无真实模型、无后端、无身份认证与业务接口。页面刷新会清除交互状态。申请、审批、投递均只更新内存，不发送到任何业务系统。文件选择用于展示文件名，不上传。年假演示按自然日计算，正式产品需接入排班与制度；未展示的专业流程明确给出咨询或未接通说明。

本版暂不考虑移动端。输入语音依赖浏览器能力；主要演示路径通过文字输入与快捷问题完成。

## 维护入口

- `src/features/hr/`：业务数据、状态、GUI 页面、对话业务卡和产物适配。
- `src/components/agent-layout/conversation-data.ts`：人资场景与自然语言回退。
- `src/components/agent-layout/agent-shell.tsx`：工作区路由与产物容器。
- `src/components/agent-layout/app-config.ts`：产品身份和对话配置。
- `src/index.css`：产品样式入口；颜色使用 Pangea 语义 Token。
